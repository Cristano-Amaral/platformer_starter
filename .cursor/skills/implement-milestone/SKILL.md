# Implement Milestone
1. Read `AGENTS.md` and `docs/MILESTONES.md`.
2. Identify the current active milestone and its acceptance criteria.
3. Inspect existing code before creating new systems.
4. Give a compact plan focused only on this milestone.
5. Implement in the smallest coherent steps.
6. Configure and build Development; build Debug too when diagnostics matter.
7. Run tests or a smoke test appropriate to the milestone.
8. Fix build/test regressions before stopping.
9. Report:
   - files changed;
   - behavior implemented;
   - commands used to build/test;
   - known limitations;
   - whether acceptance criteria are satisfied.
10. Never implement the next milestone implicitly.
