# Tools

## Asset cooker
From the repository root:

```
python tools/cook_assets.py
```

Python 3, standard library only. No pip packages. No Blender.

The cooker copies known authored files from `game/assets/source/` to `game/assets/cooked/` (`textures/test_checker.png`, `models/test_static.glb`, `models/test_authored.glb`, `models/test_textured.glb`), skips a rewrite when the SHA-256 content already matches, writes `game/assets/cooked/manifest.json`, and removes only previously manifested cooked outputs that are no longer in the known asset list. GLBs are copied unchanged; they are not generated by the cooker. `.blend` files are never cooker inputs. Authoring textures used only inside Blender (Milestone 18 Base Color PNG) are not cooker inputs. See `docs/BLENDER_WORKFLOW.md`.
