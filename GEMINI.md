# Gemini / Antigravity adapter

This file is a thin entry point for Gemini CLI and Google Antigravity. It is not a second development workflow.

Follow the repository instructions:

- `AGENTS.md`
- `DEVELOPMENT_WORKFLOW.md`
- the active `docs/milestones/MILESTONE_<N>.md`

Antigravity also loads `AGENTS.md` from the repository root. Use that file and `DEVELOPMENT_WORKFLOW.md` as authority. The always-on workspace rule is `.agents/rules/repository-workflow.md`.

After implementation, STOP. Do not commit, push, merge, close the milestone, or begin the next milestone.
